## Как изучать проекты

Начните с [портфолио](https://github.com/Lavrentiy123/portfolio): в каждом кейсе указаны задача, моя роль, результат и доступный код. В этом репозитории открывайте README конкретного прототипа и его исходники.

Материалы имеют разную степень завершённости. Демонстрационные расчёты и заданные в скриптах показатели не подтверждают внедрение, качество обученной модели или экономический эффект.
